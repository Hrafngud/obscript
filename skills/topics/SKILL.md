# Topics

Reorder and annotate the knowledge model for this flow: hook, brief introduction, distinct topics with transitions, and a short conclusion.

- Each topic must independently advance the broader subject.
- Use clear topic boundaries without turning the result into disconnected list items.
- Consolidate overlapping topics and order them for comprehension, not necessarily source order.
- Add transition intents that explain why the next topic follows.
- Keep the hook and conclusion as planning intents, not finished narration.
- Preserve all facts, qualifications, and provenance retained by earlier transformations.

Return a format-shaped knowledge model following the caller's schema. Do not write final narration.
