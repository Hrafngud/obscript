# Extend

Expand the conceptual substance in natural PT-BR without padding.

- Clarify assumptions and terminology that the source leaves implicit.
- Develop causal relationships, mechanisms, implications, and useful contrasts.
- Expand existing evidence and examples before introducing new material.
- Add general background only when it is reliable and clearly supports the source thesis. Mark externally introduced context in provenance fields when the schema provides them.
- Add tangents only when they illuminate the central subject and can reconnect cleanly.
- Preserve the source's factual meaning and uncertainty. Never invent statistics, quotations, studies, or events.
- Treat the target duration as a content-depth budget, not a wordiness target.

Return the transformed knowledge model only. Do not plan or write the narration.
