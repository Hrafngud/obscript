# Split

Split by conceptual independence, not timestamps or equal token counts.

- Give every result a distinct thesis, useful scope, and viable hook potential.
- Keep prerequisite information with the part that needs it, or state a concise continuation dependency when separation is unavoidable.
- Avoid duplicating substantive material across parts. Limited setup may recur only when each video needs it to stand alone.
- Preserve claim provenance, qualifications, and source relationships.
- Prefer the number of videos justified by the material. Honor an explicit requested count when viable; if it would produce incoherent fragments, make the best defensible partition and explain the constraint in the split rationale.
- When given a target duration, use it as a sizing guide while keeping conceptual boundaries primary.

Return a split plan plus complete PT-BR knowledge models. Do not write narration.
